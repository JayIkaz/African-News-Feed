BUG 3 — Dropdown closes immediately after opening:

Replace the Countries button click handler with this pattern to prevent the document-level outside-click listener from firing on the same click and immediately closing the dropdown:

const dropdownBtn = document.querySelector('.nav-dropdown-btn');
const dropdownEl = document.getElementById('countriesDropdown');

dropdownBtn.addEventListener('click', (e) => {
  e.stopPropagation();
  dropdownEl.classList.toggle('open');
});

document.addEventListener('click', (e) => {
  if (!dropdownEl.contains(e.target)) {
    dropdownEl.classList.remove('open');
  }
});

Remove any existing onclick="toggleDropdown()" inline handler from the button element in the HTML, as it will conflict with the addEventListener above.
