Country flags (4:3 SVG) copied from the `flag-icons` package, version 7.5.0,
which is MIT licensed (see LICENSE). Only the 51 countries listed in
`src/lib/countries.ts` are included. They are served from this site so a
reader's browser does not request them from a third party.

To add a country: copy `flags/4x3/<code>.svg` from the same package.
